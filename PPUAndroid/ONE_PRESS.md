# One-Press Build

1. Push or open the branch in GitHub.
2. Open **Actions**.
3. Select **PPU Android APK**.
4. Choose **Run workflow**.
5. Download **ppu-runtime-debug-apk** from the completed run.

Local Windows build: run `build.bat`.
Local shell build: run `./build.sh` in an Android SDK/Gradle environment.

Build toolchain: Java 17, Android API 36, Android Gradle Plugin 8.13.1, Gradle 8.13.
