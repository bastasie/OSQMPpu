# PPU Android Runtime

Comprehensive Android host for the portable PPU computational architecture.

This branch contains the complete Android project in `PPUAndroid_Comprehensive.zip`.

## One press

Open **Actions → Android APK → Run workflow**. The workflow unpacks the project, installs Java 17, Android SDK platform 36 and Gradle 8.13, then builds `app-debug.apk` and publishes it as an artifact.

It also builds automatically on pushes.

The runtime supports an SVG application surface, FPS-driven internal pole rotation, Snake/game state, touch/swipe/button/trigger input, native bounded PPU kernels, PPUJ carrier inspection, carrier import, state persistence, and JPEG/SVG/PNG export.
