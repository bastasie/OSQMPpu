# PPU Browser / PWA Runtime

No APK is required.

The standalone browser build runs the PPU SVG/state runtime in a normal browser and provides bounded JavaScript fallbacks for Monte Carlo and prime-domain execution when the Android native bridge is absent.

Deploy the contents of a browser bundle to:
- Netlify Drop
- Cloudflare Pages Direct Upload
- any ordinary static HTTPS host

The existing Canva identity used for terminology and branding is design DAHV12PFG00 ("Ppu · General Use").

The JPEG remains a persistent PPUJ carrier/inspection artifact; it is not itself an execution environment.
